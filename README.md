> A formal Statement of Applicability (SoA) tailored for a remote-first software development organization, demonstrating the analytical justification for the inclusion and exclusion of Annex A controls.

## 1. Project Overview
The Statement of Applicability is the most critical artifact in an ISO 27001 implementation. This project demonstrates the ability to evaluate the 93 controls of ISO/IEC 27001:2022 Annex A against the specific operational reality of a modern, cloud-native business. It showcases analytical decision-making in determining control applicability, drafting formal justifications, and tracking implementation status.

## 2. Business Scenario
The SoA is designed for a **Remote-First Software Development Company**. 
* **Core Business:** Developing secure backend services and APIs using modern tech stacks (e.g., Rust, Python).
* **Infrastructure:** 100% Cloud-based and containerized environments (Docker).
* **Workforce:** Fully remote; no physical corporate offices or local data centers.

This scenario requires careful consideration of cloud security controls, secure development lifecycles, and the justified exclusion of traditional physical security measures.

## 3. Key Focus Areas (Annex A Themes)
The evaluation heavily focuses on the new organizational and technological controls introduced in the 2022 update:
* **Theme 5 (Organizational):** Information security for use of cloud services.
* **Theme 6 (People):** Remote working and telecommuting security.
* **Theme 7 (Physical):** Justified exclusion of physical perimeters due to the remote-first model.
* **Theme 8 (Technological):** Secure coding, separation of environments, and vulnerability management.

## 4. Skills Demonstrated
* **Strategic Compliance:** Aligning international standards with agile development and cloud-native architectures.
* **Audit Readiness:** Providing clear, auditable justifications for control exclusions to external auditors.
* **Secure SDLC Governance:** Enforcing policies around containerization and code deployment.
